# Code de conduite

Ces dépôts adoptent le [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1.

Le texte complet est disponible sur
[contributor-covenant.org](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).

## L'engagement

Participer à ces projets doit rester une expérience sans harcèlement pour tout le monde,
quels que soient l'âge, le handicap, l'origine, l'identité ou l'expression de genre, le
niveau d'expérience, la nationalité, l'apparence, la religion ou l'orientation sexuelle.

## Signalement

Les comportements abusifs ou inacceptables peuvent m'être signalés via
[bryan-ferrando.fr](https://bryan-ferrando.fr/#contact). Tout signalement est examiné, et
l'identité de la personne qui signale reste confidentielle.

Les sanctions suivent les
[lignes directrices du Contributor Covenant 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/#application).
