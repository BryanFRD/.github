# .github

[![Sponsor](https://img.shields.io/badge/sponsor-EA4AAA?logo=githubsponsors&logoColor=white)](https://github.com/sponsors/BryanFRD)

Fichiers santé communautaire par défaut pour mes dépôts : ce qu'un dépôt ne définit pas
lui-même est hérité d'ici.

| Fichier | Rôle |
|---|---|
| `.github/FUNDING.yml` | Bouton Sponsor affiché sur chaque dépôt |
| `.github/ISSUE_TEMPLATE/` | Formulaires de bug et de demande de fonctionnalité |
| `.github/PULL_REQUEST_TEMPLATE.md` | Gabarit de pull request |
| `CODE_OF_CONDUCT.md` | Contributor Covenant 2.1 |
| `CONTRIBUTING.md` | Comment contribuer, conventions de commit et de PR |
| `SECURITY.md` | Comment signaler une faille |
| `SUPPORT.md` | Où poser une question ou signaler un problème |

Un `LICENSE` ne s'hérite pas : GitHub ne le compte pas parmi les fichiers santé
communautaire par défaut, chaque dépôt doit avoir le sien.

Mon profil se trouve dans [BryanFRD/BryanFRD](https://github.com/BryanFRD/BryanFRD), mes projets
sur [bryan-ferrando.fr](https://bryan-ferrando.fr).
