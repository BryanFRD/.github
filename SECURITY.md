# Sécurité

## Signaler une faille

**N'ouvrez pas d'issue publique.**

Utilisez l'onglet **Security → Report a vulnerability** du dépôt concerné. Si le dépôt n'a
pas cet onglet, écrivez-moi via [bryan-ferrando.fr](https://bryan-ferrando.fr/#contact).

Précisez le dépôt et la version concernés, les étapes de reproduction, et l'impact que vous
estimez. Un exemple minimal reproductible vaut mieux qu'une longue description.

## Ce à quoi vous attendre

Ce sont des projets menés sur mon temps libre, sans engagement de délai contractuel. Je
réponds sous quelques jours et je vous tiens informé de l'avancée du correctif.

Je vous crédite dans l'avis de sécurité publié, sauf si vous préférez rester anonyme.

## Versions couvertes

Seule la dernière version publiée de chaque projet reçoit des correctifs de sécurité.
