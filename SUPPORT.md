## Une question, un bug ?

Ouvrez une issue sur le dépôt concerné. Cherchez d'abord dans les issues existantes, ouvertes
comme fermées : la réponse s'y trouve peut-être déjà.

## Une faille de sécurité ?

N'ouvrez pas d'issue publique. Utilisez l'onglet **Security → Report a vulnerability** du dépôt
concerné, ou écrivez-moi via [bryan-ferrando.fr](https://bryan-ferrando.fr/#contact).

## Me soutenir

Ces projets sont développés sur mon temps libre. Si l'un d'eux vous est utile, vous pouvez me
soutenir via [GitHub Sponsors](https://github.com/sponsors/BryanFRD).
